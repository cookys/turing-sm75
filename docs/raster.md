# 2080 Ti 對 40 / 50 系（原生光柵）

來源：TechPowerUp 相對效能（5060 Ti 16GB = 100）、Iceberg Tech / Puget / NanoReview 交叉核對。日期錨：2026-08。
**只描述遊戲原生光柵。** 開光追、DLSS 3/4、幀生成後 40/50 會再拉開。

| 4070 | ~110 | 約 +20–25% |

白話：**40 系對 4060 Ti，50 系對 5060。**

## 但書

- 2080 Ti：11GB 常見、也有 22GB 改件；352-bit、**616 GB/s**、250W。
- 4060 Ti 8GB / 5060 8GB：128-bit，頻寬 288 / 448 GB/s。1440p 堆貼圖時 2080 Ti 常贏 8GB 卡。
- 5060 Ti 16GB 把顯存優勢拿回去。
- Iceberg：5060 vs 2080 Ti，1080p 原生 5060 快不到 5%，1440p 幾乎沒差。
